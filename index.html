Reading Live 결과 화면 확인 안내

Reading Live 학습이 끝난 뒤 나오는 결과 화면을 확인해 주세요. 아래 항목은 현재 테스트가 어렵습니다. 수요일 이후 테스트 가능하며, 지금은 나머지 내용이 화면에 잘 보이는지 살펴봐 주세요.

확인 방법

Listen Up, Read On, Speak Out 학습을 끝까지 진행한 뒤 각 결과 화면을 열어 주세요. 글자와 숫자, 학습 결과가 화면에 잘 보이는지 확인해 주세요.

수요일 이후 테스트 가능한 항목

아래 3개 항목은 아직 개발 중입니다. 숫자나 내용이 다르게 보여도 이번 확인에서는 문제로 보지 않으셔도 됩니다.
